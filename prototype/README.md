# 移动端活动页面原型

依据当前系统与最新活动参数制作，用于客户评审。

## 文件说明

- `活动页面原型.pdf`：封面 + 10 屏，A4 竖版，每页一屏并配说明。
- `活动页面原型-总览.png`：10 屏总览图，适合微信/邮件快速预览。
- `screens/01-home.png` ～ `screens/10-modal-screen.png`：单屏高清图，750×1624（2 倍图），可直接插入方案或 PPT。
- `index.html`：浏览器打开可查看 10 屏总览；图片使用相对路径。
- `cover.png`：PDF 封面单独图。

| 编号 | 页面 | 说明 |

| 01 | 活动首页 | 主题、剩余机会、累计积分、达标线、开始入口 |
| 02 | 活动规则 | 分值、每题 2 分钟、80 分达标、复活、六类奖品、评优三档 |

| 04 | 答题页 · 多选 | 多选全对才得 12 分 |

| 06 | 结果页 · 未达标 | 76 分算例、当日复活 |
| 07 | 抽奖页 | 六格转盘，六类奖品 |

| 10 | 话费领取手机号 | 活动结束后填写手机号，统一发放话费 |

## 设计说明

- 主色为警察蓝，辅以金色奖项点缀；抽奖转盘单独使用红金配色，扇区交替红/米色并加金色外圈。
- 不使用盾牌标识、“平安呼伦贝尔”字样和英文。
- 首页使用“利刃出鞘”主题背景图。
- 抽奖采用六格转盘，替代原翻牌形式。
- 答题选项使用中文序号，结果页不展示答案解析。
- 话费奖励只填写手机号；手机号仅用于活动话费发放，不会用于其他用途或向无关第三方泄露。

## 说明

- 页面内积分、昵称、订单号、排名均为示意数据。
- 正式题库、奖品档位、活动时间和主办文案以主办方最终确认为准。
- 原型为视觉与交互示意，不是可提交答卷的真实活动页；真实系统见演示地址。
- 页面按 375×812 手机视口设计，已验证 320–430px 无横向溢出。

## 修改方式

源文件在 `static/prototype/`，由项目根目录的 `build_prototype.py` 生成；截图脚本为 `capture-prototype.mjs`，PDF 合成脚本为 `build_prototype_pdf.py`。修改文案或样式后依次运行即可重新导出。
