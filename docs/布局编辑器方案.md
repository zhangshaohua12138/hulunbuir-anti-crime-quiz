# 拖拽式自定义布局方案

## 目标

超级管理员可以把首页拆成区块，拖拽排序、显示/隐藏、修改区块参数；运营账号只能使用已发布布局，不能编辑。

当前 6 套主题解决“整体风格差异”，拖拽布局解决“同一套主题下的页面结构差异”。

## 两层配置

1. **主题层**
   - 模板：政府风、金秋风、国庆风、新年风、元宵风、重阳风
   - 主题色、背景图、字体层级
   - 由 `template`、`themeColor`、`heroImage` 控制

2. **布局层**
   - 区块顺序
   - 区块显示/隐藏
   - 区块参数，例如奖品显示数量、是否显示步骤条
   - 保存为 JSON，按活动/单位区分

## 区块模型

首页建议先拆成这些可拖拽区块：

```text
hero          顶部主视觉
stats         机会/积分/达标分数
cta           开始答题按钮
latest        最近成绩入口
steps         活动步骤
prizes        奖品说明
notice        提示说明
features      规则/榜单/奖品三个入口
ranking       排行榜预览（可选）
```

每个区块：

```json
{
  "id": "stats",
  "type": "stats",
  "visible": true,
  "props": {
    "fields": ["remaining", "points", "passScore"],
    "columns": 3
  }
}
```

完整布局：

```json
{
  "version": 1,
  "template": "2",
  "blocks": [
    { "id": "hero", "type": "hero", "visible": true, "props": {} },
    { "id": "stats", "type": "stats", "visible": true, "props": { "columns": 3 } },
    { "id": "cta", "type": "cta", "visible": true, "props": {} },
    { "id": "prizes", "type": "prizes", "visible": true, "props": { "limit": 2 } },
    { "id": "features", "type": "features", "visible": false, "props": {} }
  ]
}
```

## 后台交互

- 左侧：可用区块列表
- 中间：手机预览画布
- 右侧：选中区块的参数
- 拖拽排序
- 每个区块有显示/隐藏开关
- 支持撤销/重做
- 保存草稿、预览、发布
- 发布前做结构校验：hero 必须存在、cta 必须存在、不能全部隐藏

## 技术实现

当前原生 JS 版本：

- 用 SortableJS 做拖拽，不引入整套框架
- 区块注册表 `blocks = {hero, stats, cta, ...}`
- `renderLayout(layout, data)` 按 JSON 顺序渲染
- 布局保存在 `settings` 的 `layout` 字段
- 预览用同源 iframe 或独立预览路由

转 Vue 后：

- `BlockRenderer` 组件按 `type` 动态渲染
- 拖拽用 `vuedraggable` / `dnd-kit`
- 布局 JSON 不变，后端接口不变
- 后台编辑器和前台渲染共用同一套区块定义

## 权限

- 超级管理员：编辑、预览、发布布局
- 运营账号：只能查看当前布局和使用，不可修改
- 普通用户：无感知

## 实施顺序

1. 先做区块注册表和 `renderLayout`，用固定 JSON 渲染
2. 后台加布局 JSON 编辑/预览
3. 加拖拽排序和显示/隐藏
4. 加区块参数
5. 加草稿/发布/版本回滚
6. 转 Vue 时复用同一套布局 JSON

## 兼容原则

- 现有 6 套主题继续可用
- 没有自定义布局时，使用当前主题默认布局
- 自定义布局只覆盖首页，答题、结果、排行榜先保持现有结构
- 每次发布保留上一版，可回滚
