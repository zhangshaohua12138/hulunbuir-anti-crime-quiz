## 结论

- 原生 H5 与管理后台分离后，权限边界正常
- Vue 管理后台按需加载，静态资源响应正常
- API 读性能足够当前规模
- SQLite 写操作串行，p95 约 1.16 秒
- 正式高并发场景仍建议 PostgreSQL

## 仍需注意

- `/vue/` 是公开路径，后台登录前仍可访问登录页
- 当前没有 2FA、WAF 或后台 IP 白名单
- 管理后台路径建议后续改为随机路径或接入访问控制
- 备份目前只在本机，告警 Webhook 未配置
- 正式上线前必须做微信真机回归和真实支付联调
