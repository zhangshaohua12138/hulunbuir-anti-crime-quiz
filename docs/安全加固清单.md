# 安全加固清单

## 已实施

### 传输与响应头

- 全站 HTTPS，HTTP 301 跳转 HTTPS。
- HSTS：`max-age=31536000; includeSubDomains`。
- `X-Frame-Options: DENY`。
- `X-Content-Type-Options: nosniff`。
- `Referrer-Policy: strict-origin-when-cross-origin`。
- `Permissions-Policy` 关闭摄像头、麦克风、定位。
- Nginx `server_tokens off`。
- Nginx 对 `/api/` 限流 30 请求/秒，对 `/api/admin/login` 限流 5 次/分钟。

### 登录与会话

- 管理员密码使用 PBKDF2-SHA256（120000 轮）哈希存储。
- 后台分超级管理员和运营账号两级权限。
- 运营账号不能修改个性主题、微信配置、账号、活动名称或重置活动，服务端强制校验。
- 管理员会话 8 小时，普通用户会话 24 小时。
- Cookie 使用 HttpOnly、SameSite=Lax，生产环境加 Secure。
- 管理员登录有 IP 级失败限流。
- 账号密码最少 12 位；超级管理员可重置任意后台账号密码。

### 接口与业务

- SQL 全部参数化，表名来自固定白名单。
- CSRF：校验 Origin、Sec-Fetch-Site，拒绝跨站写操作。
- 微信 OAuth 使用 state 随机值和过期时间，防止重放。
- 静态文件路径解析校验，阻止目录穿越。
- 图片上传限制 PNG/JPG/WEBP、5MB，使用随机文件名，校验文件头。
- 抽奖、预算、库存、发奖在同一 SQLite 事务内校验，防止并发超发。
- 后台密钥（AppSecret、商户密钥、APIv3 密钥）不回显，接口只返回“是否已配置”。
- 敏感配置只允许超级管理员修改。

## 主要攻击面与防护

| 攻击 | 防护 |
|---|---|
| 暴力破解管理员密码 | Nginx 5 次/分钟 + 应用 IP 限流 + 12 位密码 + 可扩展 2FA |
| 撞库/弱密码 | PBKDF2 哈希、强密码策略、账号可停用 |
| CSRF | Origin 校验、SameSite Cookie、只接受同源写请求 |
| XSS | 输出统一 `esc` 转义、CSP、配置文案不直接插入 HTML |
| SQL 注入 | 参数化查询、固定表名白名单 |
| 目录穿越 | 静态文件路径 resolve 后校验必须位于 static 目录 |
| 恶意上传 | 文件头校验、大小限制、随机文件名、只允许位图 |
| 越权访问 | 会话角色校验、运营账号服务端权限拦截 |
| 重复领奖/重复发红包 | 事务、唯一约束、商户单号幂等、先查后发 |
| 红包超发 | 总预算、每日预算、库存、每日投放量四重校验 |
| OAuth 重放 | state 随机值、过期时间、一次性消费 |
| DDoS/刷接口 | Nginx 限流、建议叠加 Cloudflare/WAF |
| 密钥泄露 | 页面不回显、数据库权限 640、建议环境变量/密钥管理 |

## 上线前必须完成

1. **轮换已在聊天中出现过的密钥**
   - 公众号 AppSecret
   - APIv2 密钥
   - APIv3 密钥
   - 超级管理员密码
2. **后台访问加一层保护**
   - 推荐 Cloudflare Access、VPN 或 Nginx IP 白名单限制 `/admin` 和 `/api/admin/`。
3. **备份**
   - SQLite 在线备份，至少每日一次，保留 14 天，备份文件加密并异地存放。
4. **监控**
   - 监控 5xx、登录失败、红包失败、预算消耗、磁盘、证书到期。
5. **依赖与系统更新**
   - 定期更新 Python 依赖、Nginx、系统安全补丁。
6. **隐私与合规**
   - 隐私告知、数据保留期限、活动结束后删除或移交用户数据。
   - ICP 接入备案、微信支付商户主体和合同一致。

## 当前仍需注意

- 后台和 API 目前直接暴露在公网，只有密码和限流保护，没有 2FA/WAF。
- 微信/支付密钥保存在 SQLite 中，数据库文件权限已限制为 640，但生产建议迁移到密钥管理服务或环境变量。
- SQLite 单实例适合当前规模，DDoS 或高并发场景需要 CDN/WAF 和 PostgreSQL。
- 演示环境仍可被搜索引擎/扫描器发现，正式上线前应关闭演示入口或加访问控制。

## 应急处理

1. 发现异常登录：立即停用账号、重置密码、清理会话。
2. 发现密钥泄露：立即在商户/公众号后台重置密钥，更新后台配置。
3. 发现红包异常：暂停活动、停止生产模式、核对订单和商户账单。
4. 发现数据泄露：保留日志、按隐私预案通知和处置。
5. 发生 DDoS：启用 Cloudflare/WAF 或云防护，临时限制后台访问。
