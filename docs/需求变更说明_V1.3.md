# 界面与积分口径修改说明（V1.3）

日期：2026-11-13

本次按客户反馈调整，原型与真实系统同步修改：

1. **主色改为警察蓝**：替换原暖红配色，保留金色用于奖项点缀。
2. **品牌区调整**：去掉盾牌标识、“平安呼伦贝尔”字样和英文副标题；顶部只保留“扫黑除恶有奖答题 / 呼伦贝尔市 · 全民参与”。
3. **首页背景图**：增加“利刃出鞘”主题背景（`static/hero-bg.svg`），深蓝底、金色刀柄与光效；文字仍保证对比度。
4. **抽奖改为六格转盘**：替代翻牌，指针、分区、中心抽奖按钮与旋转动画；六类奖品正好对应六个扇区。
5. **积分排名口径**：仅单套 **80 分及以上**的答题得分转为积分，加抽奖获得的积分后合计排名；未达标套次不再计分，未达标用户不上榜。排行榜与“我的积分”同步。
6. **个人信息提示**：领奖表单和“我的奖品”页明确提示姓名、电话、地址仅用于活动奖品发放，不会用于其他用途或向无关第三方泄露。
7. **移除答案解析**：结果页不再展示答案与解析，后台也不再提供“展示答案与解析”开关。
8. **图标与中文文案**：底部导航、首页卡片增加线性图标；答题选项改用①②③④；清理活动页与后台的英文标题（保留订单号等必要技术数据）。

## 同步范围

- 真实系统：`static/theme.css`、`static/hero-bg.svg`、`static/app.js`、`static/index.html`、服务端积分/榜单逻辑。
- 原型：10 屏已按新主题重新导出，PDF、总览图和单屏 PNG 均已更新。
- 需求文档：V1.3 已更新积分口径、界面风格、抽奖形式和解析展示要求。

## 注意

- 原型中的积分、昵称、订单号仍为示意数据。
- 0.5 元现金红包是否可发、积分奖品是否占用中奖次数，仍需主办方/商户确认。
- 正式上线前仍需正式题库、容量评估、微信与支付联调。
