# 运维手册

## 预算

当前配置：

```text
总红包预算：2590000 分 = 25900 元
每日红包预算：370000 分 = 3700 元
自动按天数计算：关闭
```

即 `7 天 × 3700 元/天`。
当前活动时间：`2026-11-18 00:00:00` 至 `2026-11-24 23:59:59`（北京时间，共 7 天）。

## 数据库备份

- 脚本：`/opt/hulunbuir-quiz/scripts/backup.py`
- 目录：`/var/backups/hulunbuir-quiz`
- 保留：14 天
- 权限：600，仅 `quiz` 用户可读
- 定时：每天 03:00（Asia/Shanghai），systemd 持久化，错过会补跑
- 服务：`hulunbuir-quiz-backup.service`
- 定时器：`hulunbuir-quiz-backup.timer`

手动备份：

```bash
sudo systemctl start hulunbuir-quiz-backup.service
sudo ls -lh /var/backups/hulunbuir-quiz
```

恢复：

```bash
sudo systemctl stop hulunbuir-quiz
sudo cp /var/backups/hulunbuir-quiz/quiz-YYYYMMDD-HHMMSS.db /var/lib/hulunbuir-quiz/quiz.db
sudo chown quiz:quiz /var/lib/hulunbuir-quiz/quiz.db
sudo systemctl start hulunbuir-quiz
```

备份包含用户手机号和后台密钥，必须限制访问；生产建议加密后同步到异地。

## 健康监控

- 脚本：`/opt/hulunbuir-quiz/scripts/monitor.py`
- 检查：应用健康接口、数据库、磁盘使用率
- 日志：`/var/lib/hulunbuir-quiz/monitor.log`
- 频率：每 5 分钟
- 服务：`hulunbuir-quiz-monitor.service`
- 定时器：`hulunbuir-quiz-monitor.timer`

配置告警 Webhook：

```bash
sudo editor /etc/hulunbuir-quiz-monitor.env
```

```text
ALERT_WEBHOOK=企业微信或飞书机器人地址
```

没有填 Webhook 时只写本地日志，不会主动通知。

## 定时器检查

```bash
systemctl list-timers 'hulunbuir-quiz-*' --no-pager
systemctl status hulunbuir-quiz-backup.service --no-pager
systemctl status hulunbuir-quiz-monitor.service --no-pager
```

## 日志

```bash
sudo journalctl -u hulunbuir-quiz -n 100 --no-pager
sudo tail -100 /var/lib/hulunbuir-quiz/monitor.log
```

## 安全提醒

- 备份文件包含敏感数据，不要放在 Web 目录。
- 告警 Webhook 只填企业微信/飞书机器人地址，不要填公开群聊。
- 建议再配 Cloudflare/WAF 或 IP 白名单保护后台。
- 当前已按 7 天活动配置；如正式开始日期变化，只需在后台改活动开始/结束时间，保持 7 天窗口。
