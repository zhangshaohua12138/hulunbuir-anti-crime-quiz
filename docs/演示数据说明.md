# 演示数据说明

当前 demo 环境已写入一批明确标注为“演示”的数据，用于展示后台和移动端效果。

## 内容

- 12 个演示用户，昵称均以“演示-”开头
- 12 条已交卷答题记录
- 积分排行榜可展示 12 名用户
- 2 名用户达标，产生积分奖品
- 领奖记录均只有积分奖品，已发放
- 不包含实物、纪念品或邮寄类奖品

## 安全边界

- 不创建现金红包订单
- 不调用微信转账
- 不消耗红包预算
- 所有演示用户 openid 以 `demo-seed-` 开头
- 可通过后台“重置活动”清空

## 重新生成

```bash
sudo -u quiz /opt/hulunbuir-quiz/.venv/bin/python /opt/hulunbuir-quiz/scripts/seed_demo.py
```

脚本会先删除旧的 `demo-seed-` 用户及关联记录，再重新生成，不会动真实用户。
