# Vue 版前端

当前是并行开发的 Vue 3 MVP，不影响现有原生版。

## 已实现

- 首页区块渲染
- 规则页、答题页、结果页、抽奖页、排行榜、我的奖品
- 微信 OAuth 登录回跳、关注公众号引导
- Vue 管理后台：概览、活动配置、题库（含 Excel 导入）、奖品、用户、记录/发奖操作、账号、微信配置（公众号/支付/转账/红包文案/证书分类）
- 活动重置、解除封榜、账号重置密码
- 分享复活遮罩、返回自动领取
- 实物/话费领奖信息登记
- 答题答案自动保存、倒计时交卷
- 9 种基础区块：主视觉、数据卡、答题按钮、最近成绩、步骤、奖品、提示、功能入口、榜单
- 自定义组件：文本、图片、搜索框、按钮、分割线、轮播图、Banner 图，可重复添加
- 每个自定义组件可改内容、颜色、字号、圆角、对齐、跳转链接
- 图片组件、Banner、轮播图支持在设计器内直接上传
- 管理员登录
- 两栏设计器：左侧组件库/属性，右侧实时预览
- 点击右侧区块高亮并展开属性，拖动区块排序
- 拖拽排序
- 上移/下移/删除/显示隐藏
- 3 套布局预设
- 自定义命名模板：保存、套用、删除
- 主题配色编辑：9 个颜色项，保存到活动配置
- 手机实时预览
- 保存到后端 `/api/admin/layout`
- 主题色、背景、卡片、文字等 CSS 变量

## 本地开发

```bash
cd vue
pnpm install
pnpm dev
```

默认代理 `/api` 到 `http://127.0.0.1:8080`，先启动项目根目录的 Python 后端。

开发地址：`http://127.0.0.1:5174/vue/`

## 构建

```bash
cd vue
pnpm build
```

产物在 `vue/dist`，部署到后端 `static/vue`，访问 `/vue/`。
