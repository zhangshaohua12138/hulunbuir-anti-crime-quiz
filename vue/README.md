# Vue 管理后台

Vue 3 + Vite + TypeScript 管理后台，只承载管理端；移动端继续使用原生 H5。

## 入口

```text
/vue/                管理后台
/vue/#/login         登录
/vue/#/admin         运营概览
/                    原生 H5
```

## 管理功能

- 运营概览
- 活动配置、预算、分享复活
- 移动端页面文案
- 题库管理、Excel 导入
- 奖品管理：新增、编辑、启停、删除
- 用户管理
- 记录与发奖
- 账号管理
- 微信配置
- 布局设计（仅超级管理员）

## 权限

- 超级管理员：全部功能。
- 运营账号：活动运营功能；不能访问主题、微信配置、账号管理和布局设计。
- 后端接口同步校验权限，不能只靠隐藏菜单。

## 开发

```bash
cd vue
pnpm install
pnpm dev
```

## 构建

```bash
cd vue
pnpm build
```

构建产物部署到 `/opt/hulunbuir-quiz/static/vue`。

## 说明

- 管理后台不承载移动端页面。
- 布局设计器保存的是 Vue 布局 JSON；当前移动端为原生 H5，暂不读取该布局。
- 页面文案中留空表示不显示；需要默认文案时手动填写。
