# Vue 版前端

当前是并行开发的 Vue 3 MVP，不影响现有原生版。

## 已实现

- 首页区块渲染
- 规则页、答题页、结果页、抽奖页、排行榜、我的奖品
- 答题答案自动保存、倒计时交卷
- 9 种区块：主视觉、数据卡、答题按钮、最近成绩、步骤、奖品、提示、功能入口、榜单
- 管理员登录
- 拖拽排序
- 上移/下移/删除/显示隐藏
- 3 套布局预设
- 自定义命名模板：保存、套用、删除
- 主题配色编辑：9 个颜色项，保存到活动配置
- 手机实时预览
- 保存到后端 `/api/admin/layout`
- 主题色、背景、卡片、文字等 CSS 变量

## 本地开发

```bash
cd vue
pnpm install
pnpm dev
```

默认代理 `/api` 到 `http://127.0.0.1:8080`，先启动项目根目录的 Python 后端。

开发地址：`http://127.0.0.1:5174/vue/`

## 构建

```bash
cd vue
pnpm build
```

产物在 `vue/dist`，部署到后端 `static/vue`，访问 `/vue/`。
